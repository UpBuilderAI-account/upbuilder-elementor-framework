# ElementorForm

## Purpose

`ElementorForm` is the framework wrapper for the native Elementor Pro `form` widget. It emits Elementor form settings and repeater field settings in JSON/export mode, and renders an Elementor-like, non-submitting form preview in preview mode.

Use this component when the target site has Elementor Pro active and should receive a native Elementor form. For per-field details, see `form-fields.md`.

## Import

```tsx
import { ElementorForm } from '@upbuilder/elementor-framework';
import type { ElementorFormProps, ElementorFormField } from '@upbuilder/elementor-framework';
```

Public exports come from `upbuilder-elementor-framework/src/index.ts`, re-exported from `src/builder/abstraction/index.tsx`.

## TypeScript API

```ts
type ElementorFormProps = BaseProps & {
  formName?: string;
  fields?: ElementorFormField[];
  formFields?: ElementorFormField[];

  showLabels?: boolean;
  markRequired?: boolean;
  labelPosition?: 'above' | 'inline';
  buttonText?: string;
  buttonSize?: 'xs' | 'sm' | 'md' | 'lg' | 'xl';
  buttonWidth?: ResponsiveValue<SliderValue>;
  buttonAlign?: ResponsiveValue<'start' | 'center' | 'end' | 'stretch'>;
  buttonIcon?: IconLike;
  buttonIconAlign?: 'left' | 'right';
  buttonIconIndent?: SliderValue;
  submitActions?: string[];
  formId?: string;
  columnGap?: ResponsiveValue<SliderValue>;
  rowGap?: ResponsiveValue<SliderValue>;
  labelColor?: string;
  fieldTextColor?: string;
  fieldBackgroundColor?: string;
  fieldBorderColor?: string;
  fieldBorderRadius?: ResponsiveValue<DimensionsValue>;
  buttonTextColor?: string;
  buttonBackgroundColor?: string;
  buttonBorderColor?: string;
  buttonHoverTextColor?: string;
  buttonHoverBackgroundColor?: string;
  labelFontSize?: ResponsiveValue<SliderValue>;
  labelFontWeight?: string | number;
  labelFontFamily?: string;
  fieldFontSize?: ResponsiveValue<SliderValue>;
  fieldFontWeight?: string | number;
  fieldFontFamily?: string;
  buttonFontSize?: ResponsiveValue<SliderValue>;
  buttonFontWeight?: string | number;

```

`BaseProps` also allows `id`, `className`, `settings`, `role`, `title`, `data-*`, `aria-*`, `positioning`, `zIndex`, and `sticky`. `settings` is merged last and can override mapped settings.

## Defaults And Required Props

No prop is required.

Default mapped settings:

| Prop | Elementor setting | Default |
| --- | --- | --- |
| `formName` | `form_name` | `Contact Form` |
| `fields` / `formFields` | `form_fields` | `[]` |
| `buttonText` | `button_text` | `Send` |

Preview defaults:

| Setting | Preview default |
| --- | --- |
| `input_size` | `sm` |
| `button_size` | `sm` when framework preview renders the button; backend builder defaults to `md`. |
| `button_align` | `stretch` when unset or invalid. |
| `button_width` | `100` percent when unset. |
| `label_position` | `above` unless set to `inline`. |
| `show_labels` | Labels show unless `showLabels={false}` maps `show_labels` to an empty string. |

`fields` takes precedence over `formFields` in the framework mapper. Backend builder accepts either `fields` or `formFields`.

## Responsive Support

Responsive props use:

```ts
type ResponsiveValue<T> = T | { desktop?: T; tablet?: T; mobile?: T };
```

Responsive mapping:

| Prop | Base setting | Responsive suffixes |
| --- | --- | --- |
| `buttonWidth` | `button_width` | `_tablet`, `_mobile` |
| `buttonAlign` | `button_align` | `_tablet`, `_mobile` |
| `columnGap` | `column_gap` | `_tablet`, `_mobile` |
| `rowGap` | `row_gap` | `_tablet`, `_mobile` |
| `fieldBorderRadius` | `field_border_radius` | `_tablet`, `_mobile` |
| `labelFontSize` | `label_typography_font_size` | `_tablet`, `_mobile` |
| `fieldFontSize` | `field_typography_font_size` | `_tablet`, `_mobile` |
| `buttonFontSize` | `button_typography_font_size` | `_tablet`, `_mobile` |

Line-height and letter-spacing are not exposed directly on `ElementorFormProps`; only font size, weight, and family are exposed for label, field, and button typography. `labelFontWeight`, `labelFontFamily`, `fieldFontWeight`, `fieldFontFamily`, `buttonFontWeight`, and `buttonFontFamily` are scalar settings.

Shared `BaseProps` positioning and sticky values also support responsive settings where the shared mapper supports them.

## Elementor JSON Mapping

JSON mode creates:

```json
{
  "elType": "widget",
  "widgetType": "form",
  "settings": {}
}
```

Settings generated by props:

| Prop | Setting | Notes |
| --- | --- | --- |
| `formName` | `form_name` | Defaults to `Contact Form`. |
| `fields` / `formFields` | `form_fields` | Repeater array normalized from `ElementorFormField`. |
| `inputSize` | `input_size` | `xs` through `xl`. |
| `showLabels` | `show_labels` | `true` -> `yes`, `false` -> empty string. |
| `markRequired` | `mark_required` | `true` -> `yes`, `false` -> empty string. |
| `labelPosition` | `label_position` | `above` or `inline`. |
| `buttonText` | `button_text` | Defaults to `Send`. |
| `buttonSize` | `button_size` | `xs` through `xl`. |
| `buttonWidth` | `button_width` | Responsive column width string after normalization. |
| `buttonAlign` | `button_align` | Responsive. |
| `buttonIcon` | `selected_button_icon` | Direct framework mapping only; not currently captured by backend JSX export. |
| `buttonIconAlign` | `button_icon_align` | Direct framework mapping only; `left` maps to `row`; `right` maps to `row-reverse`. |
| `buttonIconIndent` | `button_icon_indent` | Direct framework mapping only. |

| `formId` | `form_id` | Raw string. |
| `columnGap` | `column_gap` | Responsive slider. |
| `rowGap` | `row_gap` | Responsive slider. |
| `labelColor` | `label_color` | Label text color. |
| `fieldTextColor` | `field_text_color` | Input text color. |
| `fieldBackgroundColor` | `field_background_color` | Input background. |
| `fieldBorderColor` | `field_border_color` | Input border color. |
| `fieldBorderRadius` | `field_border_radius` | Responsive dimensions. |
| `buttonTextColor` | `button_text_color` | Submit text color. |
| `buttonBackgroundColor` | `button_background_color` | Submit background. |
| `buttonBorderColor` | `button_border_color` | Submit border color. |
| `buttonHoverTextColor` | `button_hover_text_color` | Submit hover text. |
| `buttonHoverBackgroundColor` | `button_hover_background_color` | Submit hover background. |
| `labelFont*` | `label_typography_*` | Sets `label_typography_typography = "custom"` when present. |
| `fieldFont*` | `field_typography_*` | Sets `field_typography_typography = "custom"` when present. |
| `buttonFont*` | `button_typography_*` | Sets `button_typography_typography = "custom"` when present. |

## Preview Behavior

Preview mode renders a wrapper with Elementor-like classes and attributes:

```html
<div class="elementor-element elementor-widget elementor-widget-form"
     data-widget_type="form.default"
     data-up-component="ElementorForm">
```

It renders:

| Element | Behavior |
| --- | --- |
| `<form class="elementor-form">` | `method="post"`, `name` and `aria-label` from `form_name`; submit is prevented with `event.preventDefault()`. |
| hidden `form_id` input | Uses the generated element id, not the optional `formId` setting. |
| `.elementor-form-fields-wrapper` | Uses `elementor-labels-inline` or `elementor-labels-above`. |
| each field group | Uses `elementor-field-type-{type}`, `elementor-field-group-{custom_id}`, and `elementor-col-{width}` classes. |
| submit group | Uses `elementor-field-type-submit`, `elementor-col-{buttonWidth}`, and `e-form__buttons`; inline style sets width/flex-basis. |
| submit button | Renders optional `selected_button_icon` and `button_text`. |

Preview CSS covers field wrapper gaps, field group spacing, label typography/color, field color/background/border/radius/typography, submit button color/background/border/typography, hover colors, responsive row/column gaps, responsive border radius, and shared widget positioning.

The preview is not a live Elementor form submission runtime. It does not send email, webhooks, redirects, or other submit actions.

## Parser And Backend Export Notes

| Layer | Mapping |
| --- | --- |
| React parser | Recognizes `ElementorForm` as a framework widget and captures `formFields`, `fields`, `formName`, `buttonText`, `buttonSize`, `buttonAlign`, `inputSize`, `showLabels`, `markRequired`, `labelPosition`, `submitActions`, and `formId`. Style props captured include gaps, label/field/button colors, field radius, button width, and label/field/button typography props. It does not currently capture `buttonIcon`, `buttonIconAlign`, or `buttonIconIndent`. |
| Elementor type mapping | `COMP_TYPE_TO_ELEMENTOR.ElementorForm = { elType: "widget", widgetType: "form" }`. |
| Elementor builder | Has a `case "ElementorForm"` that builds native form settings and accepts JSON-string or array field data through `safeParseJsonArray`. |
| Elementor parser | Reverse maps `widgetType: "form"` back to `ElementorForm`. |
| Validator | Allows native `form` settings and checks `button_width`, `button_width_tablet`, `button_width_mobile`, and field widths against Elementor's native column classes. |
| Platform validation | Lists `ElementorForm` in `ELEMENTOR_PRO_WIDGETS`. |

Backend cleanup removes generic typography/title settings from `form` widgets so form-specific typography groups are used instead.

## Caveats And Inconsistencies

- Requires Elementor Pro on the target WordPress site.
- Framework preview button size defaults to `sm`; backend builder defaults exported parsed forms to `md` when `buttonSize` is absent.
- Framework `buttonWidth` normalization can round any numeric slider to a percent string. Backend validation only accepts native Elementor column widths: `10`, `11`, `12`, `14`, `16`, `20`, `25`, `30`, `33`, `40`, `50`, `60`, `66`, `70`, `75`, `80`, `83`, `90`, `100`.
- Framework `formId` maps to `form_id`, but preview's hidden `<input name="form_id">` uses the element id.
- Framework fields support `css_classes`, `field_html`, `inline_list`, `select_size`, `min`, and `max`; backend builder additionally accepts upload/acceptance-specific keys such as `file_types`, `allowed_types`, `max_files`, `max_file_size`, and `acceptance_text`.
- The preview does not implement Elementor submit actions.

## Example

```tsx
import { ElementorForm } from '@upbuilder/elementor-framework';

export function ContactForm() {
  return (
    <ElementorForm
      formName="Contact"
      formId="contact"
      fields={[
        { type: 'text', label: 'Name', custom_id: 'name', required: true, width: '50' },
        { type: 'email', label: 'Email', custom_id: 'email', required: true, width: '50' },
        { type: 'textarea', label: 'Message', custom_id: 'message', rows: 5 },
      ]}
      submitActions={['email']}
      buttonText="Send message"
      buttonSize="md"
      buttonWidth={{ desktop: 33, mobile: 100 }}
      buttonAlign={{ desktop: 'start', mobile: 'stretch' }}
      columnGap={{ desktop: 16, mobile: 0 }}
      rowGap={16}
      labelColor="#111827"
      fieldBorderColor="#d1d5db"
      fieldBorderRadius={6}
      buttonBackgroundColor="#0f766e"
      buttonTextColor="#ffffff"
    />
  );
}
```
