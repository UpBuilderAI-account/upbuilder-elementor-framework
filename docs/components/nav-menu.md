# NavMenu

## Purpose

`NavMenu` is the framework wrapper for the native Elementor Pro `nav-menu` widget. In JSON/export mode it emits a widget node whose `widgetType` is `nav-menu`; in preview mode it renders an Elementor-like menu shell from a supplied item tree or a small fallback item list.

This component is for WordPress menu rendering in Elementor. The `menu` prop is the important export value because Elementor PHP resolves the actual WordPress menu from that slug. The `items` prop is preview-only and is not written to Elementor settings.

## Import

```tsx
import { NavMenu } from '@upbuilder/elementor-framework';
import type { NavMenuProps, NavMenuItem } from '@upbuilder/elementor-framework';
```

Public exports come from `upbuilder-elementor-framework/src/index.ts`, re-exported from `src/builder/abstraction/index.tsx`.

## TypeScript API

```ts
type NavMenuItem = {
  text: string;
  url?: string;
  link?: LinkLike;
  children?: NavMenuItem[];
  _id?: string;
};

type NavMenuProps = BaseProps & {
  menu?: string;
  menuName?: string;
  items?: NavMenuItem[];
  layout?: 'horizontal' | 'vertical' | 'dropdown';
  align?: ResponsiveValue<'start' | 'center' | 'end' | 'justify'>;
  pointer?: 'none' | 'underline' | 'overline' | 'double-line' | 'framed' | 'background' | 'text';
  pointerAnimation?: string;
  submenuIcon?: IconLike;
  dropdown?: 'mobile' | 'tablet' | 'none';
  fullWidth?: boolean;
  textAlign?: ResponsiveValue<'start' | 'center' | 'end' | 'left' | 'right'>;
  toggle?: 'burger' | 'none';
  toggleIcon?: IconLike;
  toggleActiveIcon?: IconLike;
  toggleAlign?: ResponsiveValue<'start' | 'center' | 'end' | 'left' | 'right'>;
  textColor?: string;
  textColorHover?: string;
  textColorActive?: string;
  pointerColor?: string;
  pointerColorActive?: string;
  menuItemPaddingH?: ResponsiveValue<SliderValue>;
  menuItemPaddingV?: ResponsiveValue<SliderValue>;
  menuSpaceBetween?: ResponsiveValue<SliderValue>;
  dropdownBackgroundColor?: string;
  dropdownTextColor?: string;
  dropdownTextHoverColor?: string;
  dropdownTopDistance?: ResponsiveValue<SliderValue>;
  toggleColor?: string;
  toggleBackgroundColor?: string;
  toggleSize?: ResponsiveValue<SliderValue>;
  fontSize?: ResponsiveValue<SliderValue>;
  fontWeight?: string | number;
  fontFamily?: string;
  lineHeight?: ResponsiveValue<SliderValue>;
  letterSpacing?: ResponsiveValue<SliderValue>;
};
```

`BaseProps` also allows `id`, `className`, `settings`, `role`, `title`, `data-*`, `aria-*`, `positioning`, `zIndex`, and `sticky`. `settings` is merged last and can override mapped settings.

## Defaults And Required Props

No prop is required.

Default mapped settings:

| Prop | Elementor setting | Default |
| --- | --- | --- |
| `menu` | `menu` | `primary-menu` |
| `menuName` | `menu_name` | `menu` or `Primary Menu` |
| `layout` | `layout` | `horizontal` |
| `pointer` | `pointer` | `underline` |

Preview defaults:

| Condition | Behavior |
| --- | --- |
| `items` omitted or empty | Renders `Home`, `About`, `Contact` fallback links. |
| `toggle` omitted | Renders the menu toggle because only `toggle="none"` suppresses it. |
| submenu item without `submenuIcon` | Uses `fas fa-caret-down`. |
| toggle without `toggleIcon` | Uses `fas fa-bars`. |

## Responsive Support

Responsive props use the framework `ResponsiveValue<T>` shape:

```ts
type ResponsiveValue<T> = T | { desktop?: T; tablet?: T; mobile?: T };
```

Responsive mapping:

| Prop | Base setting | Responsive suffixes |
| --- | --- | --- |
| `align` | `align_items` | `_tablet`, `_mobile` |
| `textAlign` | `text_align` | `_tablet`, `_mobile` |
| `toggleAlign` | `toggle_align` | `_tablet`, `_mobile` |
| `menuItemPaddingH` | `padding_horizontal_menu_item` | `_tablet`, `_mobile` |
| `menuItemPaddingV` | `padding_vertical_menu_item` | `_tablet`, `_mobile` |
| `menuSpaceBetween` | `menu_space_between` | `_tablet`, `_mobile` |
| `dropdownTopDistance` | `dropdown_top_distance` | `_tablet`, `_mobile` |
| `toggleSize` | `toggle_size` | `_tablet`, `_mobile` |
| `fontSize` | `menu_typography_font_size` | `_tablet`, `_mobile` |
| `lineHeight` | `menu_typography_line_height` | `_tablet`, `_mobile` |
| `letterSpacing` | `menu_typography_letter_spacing` | `_tablet`, `_mobile` |

`fontWeight` and `fontFamily` are desktop-only scalar settings. Shared `BaseProps` positioning and sticky values also support responsive settings where the shared mapper supports them.

## Preview Behavior

Preview mode renders a wrapper with Elementor-like classes and attributes:

```html
<div class="elementor-element elementor-widget elementor-widget-nav-menu"
     data-widget_type="nav-menu.default"
     data-up-component="NavMenu">
```

It emits:

| Element | Behavior |
| --- | --- |
| `.elementor-menu-toggle` | Rendered unless `toggle="none"`. It is static and has `aria-expanded="false"`. |
| main `<nav>` | Rendered when `layout !== "dropdown"`. |
| dropdown `<nav>` | Always rendered, hidden with `aria-hidden` unless `layout === "dropdown"`. |
| nested items | Recursive `children` render as `.sub-menu elementor-nav-menu--dropdown`; hover CSS displays the submenu. |
| `data-settings` | Includes `layout`, `dropdown`, `toggle`, and `full_width`. |

Preview CSS covers horizontal/vertical/dropdown layout, item colors, item padding, typography, menu gap, dropdown background/text colors, toggle color/background/size, responsive tablet/mobile rules, and shared widget positioning.

The preview does not run Elementor's native JS. The toggle is visual only unless surrounding preview infrastructure adds native Elementor behavior.

## Parser And Backend Export Notes

Backend support is broader than the public framework component:

| Layer | Mapping |
| --- | --- |
| React parser | Recognizes `NavMenu` as a framework widget and captures nav props including `menu`, `menuName`, `layout`, `pointer`, `pointerAnimation`, `submenuIcon`, `dropdown`, `fullWidth`, `textAlign`, `toggle`, `toggleIcon`, `toggleActiveIcon`, and `toggleAlign`. Style props captured include menu padding, spacing, dropdown colors, toggle colors/size, active/pointer colors, and typography props. |
| Elementor type mapping | `COMP_TYPE_TO_ELEMENTOR.NavMenu = { elType: "widget", widgetType: "nav-menu" }`. |
| Elementor builder | Has a `case "NavMenu"` that builds the same native settings. It also accepts `menuSlug` as an alias for `menu`. Backend default `align_items` is `center`; framework default leaves it unset. |
| Elementor parser | Reverse maps `widgetType: "nav-menu"` back to `NavMenu`. |
| Validator | Allows `nav-menu` and its native nav settings; `nav-menu` is also included in `ELEMENT_ALIGN_WIDGETS`. |
| Platform validation | Lists `NavMenu` in `ELEMENTOR_PRO_WIDGETS`. |

Backend cleanup removes generic typography/title settings from `nav-menu` and preserves `align_items`. It also converts any accidental `_padding_horizontal_menu_item` or `_padding_vertical_menu_item` settings to the unprefixed native names.

## Caveats And Inconsistencies

- Requires Elementor Pro on the target WordPress site; framework and backend can emit JSON, but the native widget must exist in WordPress.
- `items` is preview-only. Exported Elementor JSON only references `menu`.
- Framework default `align` is unset; backend builder defaults `align_items` to `center` for parsed/exported `NavMenu` style props.
- Framework accepts `IconLike` objects for `submenuIcon` and toggle icons; backend builder's `submenuIcon` path primarily treats `submenuIcon` as a string, while toggle icons go through the shared selected-icon normalizer.
- Responsive support in the framework is desktop/tablet/mobile. Backend parser also recognizes `Laptop` suffixes generically, but the framework component mapper does not emit laptop settings.
- The toggle preview is static and does not open/close the dropdown by itself.

## Example

```tsx
import { DocumentBuilder, Flexbox, NavMenu } from '@upbuilder/elementor-framework';

export function Header() {
  return (
    <DocumentBuilder title="Header">
      <Flexbox direction="row" justify="space-between" alignItems="center">
        <NavMenu
          menu="primary-menu"
          menuName="Primary Menu"
          layout="horizontal"
          dropdown="tablet"
          align={{ desktop: 'end', tablet: 'center', mobile: 'center' }}
          menuSpaceBetween={{ desktop: 28, mobile: 10 }}
          menuItemPaddingH={{ desktop: 8, mobile: 4 }}
          textColor="#1f2937"
          textColorHover="#0f766e"
          pointer="underline"
          pointerAnimation="grow"
          toggleSize={{ tablet: 24, mobile: 22 }}
          items={[
            { text: 'Home', url: '/' },
            {
              text: 'Services',
              url: '/services',
              children: [
                { text: 'Design', url: '/services/design' },
                { text: 'Build', url: '/services/build' },
              ],
            },
            { text: 'Contact', url: '/contact' },
          ]}
        />
      </Flexbox>
    </DocumentBuilder>
  );
}
```
